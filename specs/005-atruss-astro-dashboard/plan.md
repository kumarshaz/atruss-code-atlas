## Summary

This plan executes the CLI rename (from `repo-analyzer` to `atruss`) and provisions an Astro Starlight application scaffold. This static site will ingest the structural output CSV/JSON/YAML and provide a high-level summary dashboard dashboard, allowing users to drill down linearly into the detailed Markdown/Mermaid docs generated by the internal engine.

**Language/Version**: Python 3.10+ (CLI), Node.js/Astro 4+ (Web)
**Primary Dependencies**: Typer (CLI rename), Astro, Starlight (Web)
**Storage**: N/A (Offline Flat Files: JSON, YAML, Markdown in `./exports/`)
**Testing**: Pytest (CLI context rename verifications)
**Target Platform**: Desktop CLI, CI Pipeline, Static File Host (GitHub Pages, S3)
**Project Type**: Python CLI Tool + Static Content Site (Astro)
**Performance Goals**: Instant offline site rendering; 0 blocking active fetch calls on initial page load.
**Constraints**: Fully database-free constraint remains in place; Astro must build 100% statically at build-time.
**Scale/Scope**: Handling directories with tens or hundreds of thousands of generated Markdown docs is native to Astro via Content Collections.
