# Quickstart: Atruss Astro Dashboard

This guide walks you through generating a repository discovery and pipeline analysis using the newly named CLI, then exploring the results in the web dashboard locally.

## Prerequisites

- Windows Subsystem for Linux (WSL)
- Node.js (>= 22.x) managed via `fnm` inside WSL
- Python (>= 3.10) with dependencies installed via `pip install -e .`

## 1. Run the Atruss Code Atlas CLI

First, we generate the analysis data on your local repository workspace or connected organization.

```bash
# Export your GitHub token for API extraction
export GH_TOKEN="ghp_xxxxxxxxxxxx"

# Discover repositories to generate JSON metrics
atruss discover --org your-org

# Crawl the pipelines of the discovered repositories
atruss analyze-pipeline --from-discovery ./exports/latest/repos/repositories.json
```

These commands populate the `exports/latest/` directory with JSON telemetry and markdown/Mermaid topology graphs.

## 2. Launch the Astro Dashboard

The Atruss Astro dashboard ingests this raw CLI telemetry and surfaces it within an interactive static site using the Starlight template.

```bash
# Launch your WSL environment (e.g., Ubuntu) and ensure fnm is active
# wsl -d Ubuntu

# Set Node version
fnm use 22

# Navigate to the web folder
cd web

# Install dependencies
npm install

# Start the development server
npm run dev
```

## 3. Explore the Output

Open your browser to `http://localhost:4321`.
You will see the **Atruss Code Atlas Dashboard**.
- Review the aggregate Discovery, Pipeline, and Architectural Anti-Pattern counters.
- Click on any repository link to drill down into the fully readable, Markdown/Mermaid docs generated by the internal engine without a database.
